## 🚀 Usage Examples

### 1. Language Switching

**User Action**: Click language toggle in navigation (shows "AR" when in English, shows "EN" when in Arabic)

**Result**:
- URL changes from `/en/*` to `/ar/*` (or vice versa)
- Entire UI switches language
- Layout direction changes (LTR ↔ RTL)
- Preference saved automatically

### 2. Wallet Connection

**User Action**: Click "Connect Wallet" button

**Result**:
- RainbowKit modal appears
- User selects wallet provider (MetaMask, WalletConnect, etc.)
- Wallet connects
- Button shows wallet address and balance
- Status indicator turns green

### 3. Connected Wallet Analysis

**User Action**: After connecting wallet, use Web3WalletAnalyzer component

**Result**:
- Real-time risk assessment of connected wallet
- Displays risk score, confidence, threat type
- Shows wallet balance and chain ID
- Provides security recommendations
- Includes Web3 metadata
