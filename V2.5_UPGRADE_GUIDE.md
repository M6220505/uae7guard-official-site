- Configurable alert types (Address Poisoning, Suspicious Approvals, Rug Pulls, NFT Scams)

**Setup Instructions:**

#### Telegram Setup:
1. Navigate to Dashboard → Notifications tab
2. Enable Telegram notifications
3. Get your bot token from [@BotFather](https://t.me/BotFather):
   - Send `/newbot` to BotFather
   - Follow the prompts to create your bot
   - Copy the token (e.g., `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)
4. Get your Chat ID from [@userinfobot](https://t.me/userinfobot):
   - Send `/start` to userinfobot
   - Copy your Chat ID (e.g., `123456789`)
5. Paste both values into the configuration
6. Click "Send Test Notification" to verify
7. Save your configuration

#### Discord Setup:
1. Navigate to Dashboard → Notifications tab
2. Enable Discord notifications
3. Create a webhook in your Discord server:
   - Open Server Settings → Integrations
   - Click "Create Webhook"
   - Choose a channel for alerts
   - Copy the webhook URL
4. Paste the webhook URL into the configuration
5. Click "Send Test Notification" to verify
6. Save your configuration

### 3. **Live Threat Database with External API Integration**
Enhanced risk engine with hooks to external threat intelligence APIs.

**Supported Threat Intelligence Sources:**
- **Forta Network**: Real-time security monitoring across multiple chains
- **Chainalysis**: Industry-standard AML/sanctions data
- **Etherscan**: Address labels and reputation tracking

**Key Features:**
- Automatic threat intelligence aggregation
- Weighted scoring from multiple sources (Forta 40%, Chainalysis 40%, Etherscan 20%)
- Intelligent caching (1-hour TTL) for performance
- Graceful fallback if APIs are unavailable
- 5-second timeout per API to prevent blocking

**Risk Engine Enhancements:**
```javascript
// Enable external threat APIs in risk analysis
const result = await calculateOptimizedRisk({
  walletAddress: '0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb',
  // ... other parameters
  externalThreatAPIConfig: {
    enabled: true, // Enable external APIs
    enableForta: true,
    enableChainalysis: true,
    enableEtherscan: true,
    fortaApiKey: process.env.FORTA_API_KEY,
    chainalysisApiKey: process.env.CHAINALYSIS_API_KEY,
    etherscanApiKey: process.env.ETHERSCAN_API_KEY,
    timeout: 5000, // 5 second timeout
    cacheEnabled: true,
    cacheTTL: 3600000, // 1 hour cache
  }
});

// Access external threat intelligence in results
console.log(result.detectionModules.externalThreatIntel);
/*
{
  address: "0x742d35cc...",
  timestamp: 1739635825000,
  sources: {
    forta: { enabled: true, alerts: [...], riskScore: 75 },
    chainalysis: { enabled: true, isSanctioned: false, riskLevel: "medium", riskScore: 60 },
    etherscan: { enabled: true, labels: ["Exchange"], riskScore: 0 }
  },
  combinedRiskScore: 54,
  hasActiveThreats: true,
  fromCache: false
}
*/
```

**API Keys Setup:**
Create a `.env.local` file in the project root:
```bash
# Forta Network (https://forta.org)
FORTA_API_KEY=your_forta_api_key_here

# Chainalysis (https://www.chainalysis.com)
CHAINALYSIS_API_KEY=your_chainalysis_api_key_here

# Etherscan (https://etherscan.io/apis)
ETHERSCAN_API_KEY=your_etherscan_api_key_here
```

**Performance Considerations:**
- External API calls run in parallel for optimal performance
- Caching prevents redundant API calls
- Timeout ensures analysis completes within 100ms SLA
- Internal risk engine continues to function even if external APIs fail

### 5. **Transaction Simulator**
Pre-transaction analysis that explains exactly what will happen before you sign.

**Key Features:**
- Real-time transaction simulation
- Plain-language explanations (English + Arabic)
- Automatic detection of transaction types (Transfer, Approval, Swap, Mint)
- Risk and warning identification
- Gas estimation
- Address poisoning detection
- Unlimited approval warnings
- Visual risk indicators

**Supported Transaction Types:**

#### 1. **ETH/Token Transfers**
```
What will happen:
Transfer 1.5000 ETH to 0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb

Warnings:
• Sending to a suspicious-looking address
• Address has similar prefix to your recent transactions (Address Poisoning)

Gas Estimate: ~21,000
```

#### 2. **Token Approvals**
```
What will happen:
Grant unlimited token approval to 0x7a250d5630B4cF539739dF2C5dAcb4c659F2488D

Critical Risks:
⚠️ Unlimited approval detected - contract can spend all your tokens
⚠️ Consider approving only the required amount

Warnings:
• Unverified contract address

Gas Estimate: ~46,000
```

#### 3. **DEX Swaps**
```
What will happen:
Execute token swap on decentralized exchange

Warnings:
• Ensure you understand slippage tolerance
• Verify token contract addresses before swapping

Gas Estimate: ~150,000
```

#### 4. **NFT Mints**
```
What will happen:
Mint NFT from 0xBC4CA0EdA7647A8aB7C2061c2E118A18a936f13D

Warnings:
• Verify the authenticity of the NFT collection
• Check for similar-named fake collections

Gas Estimate: ~185,000
```

**How to Use:**
1. Navigate to Dashboard → Simulator tab
2. Initiate a transaction from your connected wallet
3. Transaction data automatically loads into simulator
4. Review the plain-language explanation
5. Check for risks and warnings
6. Verify "From" and "To" addresses
7. Click "Sign Transaction" to proceed or "Reject Transaction" to cancel

**Integration Example:**
```typescript
import TransactionSimulator from '@/components/TransactionSimulator';

<TransactionSimulator
  transactionData={{
    from: address,
    to: '0x...',
    value: '0x0',
    data: '0x095ea7b3...',
  }}
  onApprove={() => {
    // User approved - proceed with signing
    signTransaction();
  }}
  onReject={() => {
    // User rejected - cancel transaction
    cancelTransaction();
  }}
/>
```

## 🔧 Troubleshooting

### Issue: Wallet won't connect
**Solution:**
- Ensure you have a Web3 wallet installed (MetaMask, Coinbase Wallet, etc.)
- Check that you're on a supported network
- Clear browser cache and reload
- Try a different wallet provider

### Issue: Notifications not sending
**Solution:**
- Verify Telegram bot token is correct (from @BotFather)
- Confirm Chat ID is accurate (from @userinfobot)
- For Discord, ensure webhook URL is valid
- Check browser console for error messages
- Test notification before saving

### Issue: External APIs not working
**Solution:**
- Verify API keys in `.env.local`
- Check API key permissions and quotas
- Ensure keys are loaded (restart dev server)
- External APIs fail gracefully - internal risk engine continues working

### Issue: Arabic text not displaying correctly
**Solution:**
- Clear browser cache
- Verify `dir="rtl"` is set on `<html>` tag
- Check that Arabic fonts are loading
- Test in different browsers

### Issue: Transaction simulator not loading
**Solution:**
- Ensure wallet is connected
- Verify transaction data is valid
- Check browser console for errors
- Try a different transaction type

```typescript
import { calculateOptimizedRisk, ExternalThreatAPIManager } from '@/lib/optimized_risk_engine';
```
