# V2.5 Upgrade Guide

## Overview

V2.5 extends the UAE7Guard website with wallet-native scanning flows, multilingual UI, and production deployment guidance.

## Added Capabilities

1. Wallet connectivity through Wagmi provider setup.
2. Transaction simulator for pre-sign risk review.
3. Notification settings storage for Telegram and Discord hooks.
4. Arabic translations with RTL routing via locale segment.
5. API-backed scanner with module-level threat breakdown.
6. Phase-1 hardening: strict payload validation, API rate limiting, optional API key auth, and live telemetry.
7. Phase-2 hardening: server-side transaction simulation using `eth_call` and `debug_traceCall` with graceful fallback.
8. Phase-3 operations: tenant-level API keys/quotas, Forta signal ingestion, and usage/evaluation dashboarding.

## Migration Steps

1. Install new dependencies from `package.json`.
2. Set `.env.local` values from `.env.example`.
3. Run `npm run build` and validate `/en` and `/ar` routes.
4. Validate `/api/analyze` with sample payloads.
5. Deploy and configure production secrets.

## Backward Compatibility

- Existing direct `/api/analyze` consumers remain supported.
- Locale-prefixed URLs are now primary for all page routes.

## Operational Notes

- External intelligence integrations degrade gracefully when provider API keys are absent.
- Notification settings are currently persisted client-side; replace with server persistence for shared team access.
